# UtopiaFacts

UtopiaFacts is a small web project that presents different conspiracy theories in a clean and simple way.  
The site includes a homepage with theory cards, a dropdown menu, and individual article pages.

## Features
- Dark-themed UI  
- List of theories loaded from JSON  
- Individual article pages generated dynamically  
- Language switch (English / Finnish)  
- Responsive layout  
- Images and long texts loaded automatically from JSON files  

## Technologies Used
- HTML  
- CSS  
- JavaScript  
- JSON  
- VS Code + Live Server  

I also used AI tools (ChatGPT) to help generate and translate text, clean content from Utopia Show videos, and structure the JSON data.

## Structure
index.html – homepage
article.html – article view
style.css – styles
script.js – logic + dynamic content
lang_en.json – English UI text
lang_fi.json – Finnish UI text
theories_en.json – theory data (EN)
theories_fi.json – theory data (FI)
img/ – images

## How to Run
1. Open the project folder in VS Code  
2. Start **Live Server**  
3. The homepage opens automatically and all pages work locally  

## Content Sources
The theory descriptions were inspired by videos from the YouTube channel **Utopia Show**  
and rewritten/translated using AI.
